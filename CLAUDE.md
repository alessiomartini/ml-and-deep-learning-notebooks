# Claude Code instructions

## Project

Machine-learning and deep-learning Jupyter notebooks with datasets.

## Workflow

- Read `README.md` and execute only the affected notebook or section first.
- Preserve notebook outputs unless regeneration is requested.
- Use deterministic seeds where the existing notebook supports them and record
  meaningful environment assumptions.
- Never fabricate metrics, plots, or training results.
- Keep model caches, credentials, and large generated artifacts out of git.
- Inspect notebook diffs carefully before committing.
